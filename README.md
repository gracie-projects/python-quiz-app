
# Python Quiz App

A beginner-friendly command-line quiz application built using Python.

## Features

- Multiple-choice Python questions
- Randomized question order
- Input validation
- Automatic score and percentage calculation
- Explanations after each answer
- Persistent high score stored in JSON
- Replay option

## Requirements

- Python 3.10 or newer
- No external packages required

## How to Run

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Run:

   ```bash
   python main.py
   ```

## Technologies Used

- Python
- JSON file handling
- Randomization
- Functions and loops
- Exception handling

## Project Structure

```text
quiz_app/
├── main.py
├── README.md
└── high_score.json   # Created automatically during play
```

## Learning Outcomes

This project demonstrates functions, dictionaries, loops, conditional statements, input validation, exception handling, random selection, and persistent data storage.
